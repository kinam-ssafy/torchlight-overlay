# 가중치 직접 편집 실험

사용자가 제시한 [Weight-Space Programming 연구](https://rikiyat.github.io/blog/weight-space-programming/)와
[공개 실험 기록](https://github.com/RikiyaT/lm_understand-logs)을 확인하고,
현재 추천기의 계수를 직접 해석해 제한된 후보를 만든다. 연구의 Qwen 결과는 반복 출력 장애를
교정한 실험이며, 모든 모델의 능력 향상을 보장하는 방법은 아니다. 원문은 Gemma에서
유의미한 개선에 실패한 결과도 보고한다. 이 프로젝트의 실험은 해당 연구의 재현이 아니다.

## 수정 가설

현재 모델은 신경망이 아니라 13라운드 x 656개 특징의 선형 가치 함수다.
`value.rs`의 입력 순서와 `game.rs`의 선택 가능 시점을 기준으로 다음 세 후보를 고정한다.

- `resource-contract`: 추가 도구 리롤을 음수로 평가하는 8/9라운드 계수 2개를 0으로,
  물약이 더 나오지 않는 11~13라운드의 물약 리롤 계수 3개를 0으로 바꾼다. 총 5개 수정.
- `grounded-10`: 기존 원시 예측 90% + 현재 상한 점수 특징 10%에 위 자원 교정을 적용한다.
- `grounded-25`: 같은 방식으로 75% + 25%를 사용한다.

현재 점수 특징은 기존 모델의 `min(score, 950000)/1000000`을 그대로 사용하며,
최종 출력은 기존 CPU 엔진이 0~840000으로 제한한다. 계수 조합의 보수성이 실제 저점을
높인다는 보장은 없다. 도구 효과로 현재 점수도 사라질 수 있으므로 성공 보장값으로 취급하지 않는다.
도구 조합 가중치의 음수 자체는 오류로 단정하지 않으며 임의로 지우지 않는다.

## 검증 절차

훈련/경사하강 없이 계수를 편집한다. 각 후보의 모든 변경 위치와 이전/이후 값을 기록한다.
각각 880개 실제 Rust 상태에서 CPU, NumPy, CUDA float64 예측을 대조했다.
최대 오차는 0.000000001점 미만이다. 단위 테스트 3개가 통과했다.
이것은 내보내기 정확성 검사이며 추천 성능 검사가 아니다.

후보 생성 전에 선별 및 최종 시드를 정했다.

| 단계 | 시드 | 판 수/모델 | futures | CPU 스레드 |
|---|---|---:|---:|---:|
| 후보 선별 | 102000000부터 | 512 | 128 | 8 |
| 별도 최종 비교 | 103000000부터 | 4096 | 256 | 8 |

기존 모델과 후보의 시드를 맞춘다. 선별 결과로 후보 하나를 고정하고, 최종 비교 중에는
계수와 표본 수를 바꾸지 않는다. 기존 `gpu_gate.py`의 달성률 검정, 하위 10%, 30만 미만
빈도, CPU 시간 기준을 적용한다. 몬스터 수는 전투 시간의 대리 지표로 함께 기록한다.
배포판은 CPU로 실행하며, GPU는 개발 과정의 수치 검증에만 사용한다.
이번 실험은 시뮬레이터 안의 비교이며 실게임 규칙의 정확성이나 OCR을 증명하지 않는다.

## 실행

```powershell
python -m unittest discover -s vorax/scripts -p test_weight_edit.py
python vorax/scripts/weight_edit.py --run qa/weight-edit/run01 --engine qa/gpu-synergy/engine.exe --threads 8
python vorax/scripts/gpu_search.py screen --run qa/weight-edit/run01 --engine qa/gpu-synergy/engine.exe --threads 8 --eval-seed 102000000 --eval-games 512 --futures 128
python vorax/scripts/gpu_gate.py --run qa/weight-edit/run01 --engine qa/gpu-synergy/engine.exe --threads 8 --seed0 103000000
```

실험 상태: 후보 3개 생성, CPU/GPU 대조 및 모델별 512판 선별 완료.

| 모델 | 84만 달성 | 하위 10% 점수 | 30만 미만 |
|---|---:|---:|---:|
| 기존 | 356/512 (69.53%) | 534224 | 5 |
| resource-contract | 360/512 (70.31%) | 544261 | 5 |
| grounded-10 | 360/512 (70.31%) | 564660 | 7 |
| grounded-25 | 378/512 (73.83%) | 580067 | 5 |

선별 후보 grounded-25의 paired p=0.0945로 개선이 확정된 결과는 아니다.
부화 등 연속 특수 포션의 누락을 발견해 4096판 최종 비교는 시작하지 않고 보류했다.
새 규칙을 같은 실험 도중 섞지 않는다. 규칙 검증 후 새 실험으로 비교해야 한다.
실행별 동시 시스템 부하가 달랐으므로 기록된 실행 시간 차이를 최적화 효과로 해석하지 않는다.
기존 배포 모델과 실행 파일은 변경하지 않았다. 성능 개선이나 최적 모델 확보를 선언하지 않는다.
