# 각성체 인식과 도구 확인 복구

2026-11-04. 추천 모델 가중치 변경과 별도로 입력 및 상태 변환을 수정했다.

## 확인한 원인과 변경

- 종족 판독은 파란 이름 글자의 몇 픽셀을 변이 악마 아이콘으로 오인했다. 현대 화면 경로에서 네 종족의 밝은 아이콘 색을 비교하고, 이름 영역과 어두운 탱크 배경을 제외한다. 증거가 없거나 혼합되면 불확실로 처리하고 추천을 보류한다. 기존 참조 화면의 판독 규칙과 고정 회귀 결과는 유지한다.
- 도구 확인 안내는 이미 선택 이력으로 알고 있는 뇌 아이콘을 다시 가리켰다. 소유 이력과 실제 선택 후보를 사용해 아직 확인하지 못한 슬롯을 가리킨다. 다른 슬롯의 도구 설명이나 당시 선택지에 없던 도구로 덮어쓰지 않는다. ESC 후 같은 판 재진입에도 이력을 유지한다.
- 한 라운드에서 8,000/28,000 문턱을 모두 넘었을 때 화면 상태를 시뮬레이터로 옮기는 코드가 두 번째 보상 선택을 늦췄다. 보상 도구 화면에서 대기 중인 선택 수를 복원해 추가 라운드 효과 없이 연속 선택한다. 물약 화면의 높은 점수만으로 보상 대기를 추정하지 않는다.

## 검증

- 전체 release workspace: 90 passed, 0 failed, 0 ignored. 설치된 한국어 OCR 테스트 포함.
- 최종 재진입 트리거 정리 후 overlay 재검증: 43 passed, 0 failed, 0 ignored.
- release workspace 빌드 성공. 기존 overlay 경고 6개 유지.
- 사용자 각성체 화면: 해상도/밝기/위치 조합 243개에서 세 종족 아이콘을 올바르게 판독.
- 열린 뇌하수체 설명: 실제 OCR로 높이 720/900/1079에서 제목 판독 통과.
- 사용자 첫 화면을 완성된 실행 파일로 재생: 세 몬스터 모두 Agito, 2번 감염 구역 성모상 추천. 해당 실행의 판독 1,071ms, 추천 424ms, 전체 1,505ms. 첫 실행 및 다른 작업과 동시 실행한 단일 측정으로 지연 개선 주장은 하지 않는다.
- 같은 보드의 16,384 futures CPU 비교도 성모상 선택. 시뮬레이터의 추정이며 실제 최적 선택을 증명하지 않는다.

처음 회귀 실행의 배경색/작은 아이콘 판독 실패는 수정 후 재검증했다. 실패 로그도 로컬 QA에 보존했다.
이 검증에는 게임에서 새 판을 끝까지 진행한 결과가 포함되지 않는다. 뇌하수체 설명 원본에는 이미 그려진 안내 테두리가 있어 원본 전체를 깨끗한 실시간 입력으로 취급하지 않았다. 실제 설명 OCR과 선택 이력 복구는 분리 검증했다.

배포 모델은 그대로이며 이 문서 작성 시 설치 파일 교체와 새 릴리스는 하지 않았다.

## 후속 도구 설명 복구

2026-11-04 추가 점검:

- 다른 슬롯의 불확실한 아이콘 추측 이름을 확정 소유로 취급해, 올바르게 읽은 설명 제목을 중복으로 거부하던 조건을 수정했다. 확정된 다른 슬롯과의 중복, 실제 선택지 밖의 도구는 계속 거부한다.
- 미확인 슬롯이 두 개 이상이면 설명 OCR 자체를 건너뛰던 경로를 수정했다. 관측한 선택지 이력으로 제목에 해당하는 슬롯이 하나로 좁혀질 때만 복구한다. 클릭 안내를 따랐다고 가정해 임의 슬롯에 배정하지 않는다.
- 도구만 미확인이고 카드/종족/수치/라운드/리롤이 읽혔으면, 미확인 표시와 실제 선택지를 함께 보존한다. 추천은 계속 보류한다. 설명으로 확인한 한 슬롯의 결과는 다음 프레임에서도 유지한다. 다른 필드가 불완전한 프레임으로 전체 이력을 덮어쓰지 않는다.
- 새 판의 설명 확인에는 이전 판의 소유 이력을 사용하지 않는다.

추가 회귀는 불확실한 중복 아이콘, 두 슬롯의 순차 복구, 슬롯을 구별할 근거가 없는 설명 거부, 다른 필드가 불완전할 때 이력 보류를 검사한다. 처음 테스트의 `InstrumentsRead.clone()` 컴파일 실패는 해당 타입을 바꾸지 않고 필요한 테스트 데이터만 복제하도록 수정했다.

이 변경은 추천 가중치와 후보 가지치기를 바꾸지 않는다. 추가 후보 탐색의 512판 선별 실패를 OCR 수정으로 해결했다고 간주하지 않는다. 후속 특수 포션의 도구 보상 화면 사이 상태 복원과 미확인 게임 규칙도 별도 미완료 항목이다.

후속 수정 작업본의 전체 release workspace는 110 passed, 0 failed, 0 ignored로 통과했다. 실제 한국어 OCR 테스트 포함, 기존 경고 6개 유지. 공개 인식 수정 브랜치에도 같은 기능 패치만 적용했으며, 변경한 pipeline.rs 전체 내용이 작업본과 일치한다. 기본 모델 SHA256은 31acf8fc57fd7af8000ca0a8ab57191ecb1730d6431ce532d235fdc74c3582af 그대로다. 실게임 새 판 검증, 설치 파일 교체, 새 릴리스는 하지 않았다. 현재 실행 중인 설치본의 파일 버전은 1.0.9다.

공개 인식 수정 브랜치 자체의 전체 release workspace도 91 passed, 0 failed, 0 ignored로 통과했다. 연구 코드가 포함된 작업본의 110개와 별도로 검사한 결과다.
