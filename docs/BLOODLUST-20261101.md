# 블러드 러스트 실전 결과 조사

## 상태

2026-11-02 후속: 아래는 11월 1일 조사 당시의 상태다. 확인된 수정은 1.0.9에 반영하며, 이후 시뮬레이션과 채택하지 않은 후보는 [1.0.9 검증](STABILITY-1.0.9.md)에 기록한다. 수정 후 실전 완주의 점수 개선은 아직 확인하지 않았다.

사용자가 1.0.8 추천을 따른 두 판에서 최종 활성 289,996과 265,453을 보고했다. 소스 수정과 회귀 검증을 진행했지만 추천 품질 회복을 확인한 완주 결과는 없다. 실행 중인 배포본 교체와 새 공개 릴리스는 보류한다.

1.0.8의 256개 시드 비교는 기존 시뮬레이터 내부 비교다. 실제 게임과의 규칙 차이가 확인되었으므로 그 평균 +50.4%를 실전 개선 근거로 사용하지 않는다. 그 자료에서도 하위 10% 점수는 615,206에서 593,928로 낮아졌고, 30만 미만은 5/256에서 6/256으로 늘었다. 도구 리롤도 벤치마크는 2회, 이번 두 판은 1회였다. 평균 개선과 낮은 점수의 방지는 별개이며, 두 판의 손실이 모두 아래 오류 때문이라고 단정할 수 없다.

## 실제 기록으로 확인한 차이

- 인간 번데기 표본: 기존 코드는 X개 탱크를 중복 없이 선택하는 과정을 X번 수행했다. 첫 판 후반에 모든 탱크가 독충이면 이 구현은 각 탱크에 정확히 +40을 주지만, 실제 10라운드 이후 증가량은 +32, +32, +48, +32, +56이었다. 합계는 200으로 같고 같은 탱크가 중복 선택될 수 있다. 각 효과를 독립 추첨하도록 수정했다. 이는 효과 총량의 상향이 아니라 분포의 수정이다.
- 보유 도구 재등장: 첫 판은 이미 날가죽 구속대를 가진 상태에서 같은 도구가 다시 제시되고 선택되었다. 기존 미래 도구 풀은 보유 도구를 제거했다. 현재 모델은 제시되는 한 손의 중복만 제외한다.
- 도구 선택 라운드: 실제 2라운드 효과 적용 후 보상 도구 화면은 여전히 2라운드를 표시한다. 엔진 내부의 해당 도구 선택 상태는 다음 3라운드다. 화면 숫자를 그대로 넘기면 이미 지난 포션 라운드를 한 번 더 시뮬레이션한다. 보상 도구 화면만 엔진 변환 시 +1한다.
- 숨은 리롤: 도구 화면에 표시된 도구 리롤 숫자가 포션 리롤에도 남아 있었다. 두 자원을 각각 기억한다. 시작 화면의 포션 리롤은 3회이며, 중간 재시작으로 모르는 경우에는 리롤을 생성하지 않는다.
- 열린 포션 상자: 상자를 연 뒤에도 일반 손으로 전달되어 리롤의 카드 풀이 달랐다. 동일 라운드, 동일 탱크, 리롤 미소모, 카드 교체라는 관측으로 상자 상태를 전달한다. 추천대로 골랐다고 가정하지 않는다. 실제 상자 안에서 리롤이 사용된 기록에 맞춰 상자 손의 리롤도 후보에 포함한다.

## 검증 방법과 남은 문제

두 판의 연속 포션/플랜 기록에서 비교할 수 있는 전이 32개를 추출했다. 각 전이를 100,000개 난수 시드로 재생했을 때 기존 모델은 23개, 수정 모델은 31개에서 다음 탱크 상태와 정확히 일치하는 결과를 생성했다. 이는 실제 게임의 난수 시드를 복원했다는 뜻도, 발생 확률이 정확하다는 뜻도 아니다. 마지막 라운드에서 사용자가 첨부한 두 최종 결과로 가는 전이도 별도로 재현했다. 찾은 시드와 원래 탱크 상태를 `vorax/fixtures/live-transitions-20261101.json`에 보존하여 총 33개를 재현한다. 사용자 경로, 시각, 계정, 화면 이미지는 포함하지 않는다.

남은 1개는 둘째 판 7라운드다. 읽힌 손은 번식 가루약, 석화 척수 용액, 마취 팅크-각성체이고 추천은 3번 카드와 4번 탱크였다. 다음 읽기에서 4번 탱크의 수치 변화는 각성 결과와 맞지만 종족이 각성체가 아닌 변이 악마로 기록됐다. 당시 카드/탱크 원본 프레임이나 실제 선택 카드 기록은 저장되지 않았다. 추천 로그만으로 실제 선택을 확정하거나 인식 오류와 효과 모델 오류를 구분할 수 없다. 해당 전이는 원자료를 바꿔 통과시키거나 정상 사례로 계산하지 않았다.

원래 MIT 엔진 회귀 자료와 모든 비교 단언은 보존했다. `use_reference_model`은 그 고정 자료를 재생하는 테스트 전용 진입점이다. 제품, 일반 CLI 시뮬레이션과 학습은 수정한 현재 규칙을 사용한다. 새로운 실전 기준에 대한 점수 분포와 미해결 종족 전이 검증 전에는 개선율을 새로 주장하지 않는다.

게임 문구 대조에는 설치된 패치 6249411의 언어 자료와 기존 [TLIDB 수술 도구 자료](https://tlidb.com/en/Surgical_Instrument)를 참고했다. 난수 중복과 도구 재등장은 실제 상태 전이가 근거이며, 문구만으로 추정한 확률은 추가하지 않았다.

## 실행 검증

- `cargo test --release --locked --workspace -- --include-ignored --test-threads=1`: 78 passed, 0 failed, 0 ignored. 기존 엔진/전략/화면 회귀 자료의 단언은 유지했다.
- 최종 변경 후 숨은 포션 리롤 회귀 검사와 실전 전이 검사도 별도로 재실행했다.
- `cargo build --release --locked --workspace`: 성공. 기존 네이티브 dead-code 경고 6개가 남는다.
- .NET 코드는 수정하지 않았으며 .NET 테스트는 이번 조사에서 재실행하지 않았다.
- 실행 중인 1.0.8의 파일을 교체하지 않았고 새 ZIP/태그/릴리스를 게시하지 않았다. 수정 후 실전 완주, 점수 분포 개선 및 성능 비교는 아직 검증하지 않았다.
