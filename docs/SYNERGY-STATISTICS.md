# 수술 도구 시너지와 검증 표본 감사 (2026-11-03)

현재 모델이 최선이라고 결론 낼 근거는 없다. 이전 512게임 비교는 후보의 채택을 보류하는
근거이며, 작은 성능 차이나 낮은 점수 빈도의 개선을 확정하기에는 부족하다. 이번에는
기존 모델 입력의 구분 능력과 기존 결과의 불확실성을 확인했다. 새 가중치를 학습하거나
배포 모델을 교체한 작업은 아니다.

## 수량과 활성

엔진 점수는 탱크별 `수량 * 활성`의 합이다. 같은 합과 같은 증가 비용이라면 3 * 3이
2 * 4보다 높은 것처럼 균형이 유리하다. 하지만 카드 효과의 크기/대상/배율과 도구 발동
조건이 다르므로 무조건 수량과 활성을 같게 만드는 규칙은 적절하지 않다.

현재 수량 Q, 활성 A에 대해 증가분의 가치는 `A*dQ + Q*dA + dQ*dA`이다.
Q=200, A=50일 때 수량 +50은 +2,500점, 활성 +50은 +10,000점이다. 반면 어느 쪽이든
동일한 비율로 증가하면 현재 곱에 대한 직접적인 증가율은 같다. 문턱을 넘어 다음 턴의
도구가 발동하거나 융합하는 효과는 이후 상태까지 계산해야 한다.

사용자가 말한 핵심 기물은 수술 도구다. [TLIDB 설명](https://tlidb.com/ko/Surgical_Instrument)도
수량/활성 증가 및 특정 전략의 핵심 효과를 설명한다. 현재 엔진의 획득 문턱은
8,000점/28,000점이다(`game.rs`의 `THRESHOLDS`). 사용자가 언급한 24,000점과 다르며,
이번 감사에서 실제 게임 화면으로 문턱을 새로 검증하지는 않았다.

## 이미 계산하는 것과 학습 입력에서 잃는 것

실제 시뮬레이터는 도구의 발동 조건과 효과를 계산한다. 추천기는 도구를 보유한 상태에서
미래 플레이를 시뮬레이션한다. 기존 선형 모델도 도구 보유 여부, 도구 쌍, 종족/희귀도 개수,
일부 수량/활성 문턱 특징을 갖고 있다. 시너지를 완전히 무시하는 구조는 아니다.

그러나 현재 선형 입력은 다음 보드를 구분할 수 없다. 예제는 같은 난수 시드를 사용한
합성 상태이며, 실제 플레이 기록이나 추천 품질 개선의 증거는 아니다.

| 구분해야 할 정보 | 기존 입력 | 다음 라운드 점수 A / B |
|---|---|---:|
| 비대한 뇌하수체: 레어 각성체 유무. 종족 수와 희귀도 수는 동일 | 동일 | 28,000 / 20,000 |
| 날가죽 구속대 2개+인간 번데기 표본 1개와 구속대 1개+표본 2개 | 동일 | 57,200 / 54,400 |
| 같은 주기성 도구가 이번 라운드에 발동하거나 다음 라운드에 발동 | 동일 | 50,000 / 30,000 |

보드 가치 예측값도 각 쌍에서 정확히 같다. 예를 들어 첫 쌍은 양쪽 모두 169,257.7224점으로
예측된다. 시뮬레이터는 발동 차이를 정확하게 계산하지만 학습된 가치 함수만으로는 구분할
수 없다는 뜻이다. 이를 보정하려면 시너지 정보를 입력에 보존해야 하며, 같은 입력 구조로
데이터만 늘리는 방법은 이 차이를 직접 학습할 수 없다. 이 한계가 이전 성능 저하의 유일한
원인이라고 확정한 것은 아니다.

다음 모델 실험은 종족과 희귀도의 결합 정보, 도구별 중복 개수, 획득 라운드와 남은 발동
횟수를 먼저 표현해야 한다. 현재/후속 카드의 수량·활성 증가가 실제 점수와 도구 조건에
미치는 영향도 평가한다. 고정된 도구 티어표나 무조건 1:1 균형 보너스는 추가하지 않는다.
입력 개선만으로 성능 향상이 보장되지는 않으므로 독립 점수 검증이 필요하다.

재현 명령:

```powershell
cargo run --release --locked -p vorax --example synergy_audit --manifest-path vorax/Cargo.toml
```

## 512게임 결과의 불확실성

아래는 기존 RL 독립 비교를 다시 계산한 값이다. 학습 30만 게임과 독립 평가 512게임을
구분한다. 학습 상태 590만 개가 독립적인 성능 검증 590만 회인 것은 아니다.

| 지표 | 기존 | RL 후보 |
|---|---:|---:|
| 84만 달성 | 358/512 (69.9%) | 331/512 (64.6%) |
| 달성률 95% Wilson 구간 | 65.8% ~ 73.7% | 60.4% ~ 68.7% |
| 30만 미만 | 11/512 (2.15%) | 7/512 (1.37%) |
| 30만 미만 비율 95% Wilson 구간 | 1.20% ~ 3.81% | 0.66% ~ 2.79% |

같은 시드의 정책 간 비교에는 구간의 겹침 여부 대신 discordant pair에 대한 정확
McNemar 검정을 사용한다. 목표 달성은 후보만 성공 75/기존만 성공 102, p=0.05036이다.
30만 미만은 두 정책의 사례가 겹치지 않아 후보만 실패 7/기존만 실패 11, p=0.48068이다.
따라서 11 -> 7을 확실한 저점 개선으로 말할 수 없다. 신뢰구간은 모형과 난수 분포가
맞다는 조건의 시뮬레이션 불확실성이며 게임 규칙 누락이나 실전 OCR 오류를 포함하지 않는다.

[NIST의 비율 신뢰구간 설명](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)에
따라 개별 비율에 Wilson 구간을 표시한다. 정확 paired 검정은 두 정책의 결과가 다른
시드만으로 양측 이항 검정을 수행한다.

## 이후 검증 규모

이번 비교에서 성공 여부가 다른 비율은 177/512=34.6%였다. 유사한 비율을 가정하고,
양측 유의수준 5%, 검정력 80%를 목표로 한 paired 이항 정규근사의 필요 표본은 다음과 같다.
가정 비율을 그 95% 상한 38.8%로 높인 계획도 함께 기록한다.

| 구분하려는 달성률 차이 | 현재 추정 기준 | 보수적 계획 기준 |
|---|---:|---:|
| 5 percentage points | 1,086게임 | 1,218게임 |
| 3 percentage points | 3,015게임 | 3,383게임 |
| 2 percentage points | 6,784게임 | 7,612게임 |
| 1 percentage point | 27,134게임 | 30,447게임 |

이는 새로운 후보의 실제 분산이 같을 때의 근사 계획이다. 모든 후보나 저점 확률에 같은
검정력을 보장하지 않는다. 드문 30만 미만 결과는 별도의 빈도/신뢰구간과 paired 검정을
함께 보고, 목표 달성률만으로 저점 개선을 추정하지 않는다.

개발 도구의 출고 검증 최소 조건을 512 -> 4,096게임으로 높였다. 탐색 깊이는 최소
256 futures를 유지한다. 2 percentage points 수준의 작은 개선을 확인하려면 8,192게임
정도로 계획하고, 그보다 작은 차이는 별도 표본 설계가 필요하다. 선별은 작은 표본으로
수행하되 후보를 확정한 뒤 미사용 시드와 최종 판수를 고정한다. p값이 통과할 때까지
게임 수를 늘리거나 이미 본 검증 자료를 다시 최종 시험으로 쓰지 않는다.

이번에는 이전 후보로 4,096게임을 새로 돌린 것이 아니다. 표본 계획, 출력 신뢰구간 및
채택 조건을 수정했다. 실게임, 모델 교체와 새 릴리스는 하지 않았다.
