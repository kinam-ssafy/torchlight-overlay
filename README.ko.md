# 토치라이트 오버레이 KO 1.0.9

타르타로스와 블러드 러스트 수술 준비를 돕는 Windows x64용 비공식 추천 오버레이입니다.

1. ZIP 전체를 쓰기 가능한 폴더에 풀고 `TorchlightHelper.exe`를 실행합니다. .NET은 포함되어 있습니다.
2. 기존 TartarusSolver를 종료합니다. 같은 단축키를 사용하는 다른 오버레이와 동시에 실행하지 마세요.
3. 게임 언어를 한국어 또는 English로 선택합니다.
4. `콘텐츠 자동 감지`를 켜둡니다. 콘텐츠에 입장하면 자동으로 전환되며 탭을 바꿀 필요가 없습니다. 감지된 엔진만 실행합니다.
5. 블러드 러스트에서는 인턴 의사 세라일의 미보유 또는 1~6단계를 선택합니다. 설정은 자동 저장됩니다.

게임은 창 모드 또는 테두리 없는 창 모드를 사용합니다. 자동 인식에는 게임의 계정 관련 설정에서 로그를 활성화하고 재접속해야 합니다. 로그를 찾지 못하면 `로그 선택`으로 `UE_game/Torchlight/Saved/Logs/UE_game.log`를 지정하세요.

자동 모드의 탭은 설정 보기용입니다. `콘텐츠 자동 감지`를 끄면 탭으로 직접 엔진을 선택할 수 있습니다. 로그를 읽지 못하면 자동 전환은 대기합니다.

블러드 러스트 도중 ESC로 준비 화면을 닫으면 추천과 확인 안내가 사라집니다. 다시 열면 모델과 확정 도구 이력을 유지한 채 인식을 재개합니다.

## 추천 표시

1.0.7은 타르타로스의 한국어 PP-OCR 모델을 블러드 러스트에도 사용합니다. 한국어 모델을 우선 사용하고 Windows OCR은 보조로만 사용합니다. 모델은 블러드 러스트 엔진 시작 시 한 번 불러오며, 이후에는 같은 프로세스에서 재사용합니다. 모든 처리는 로컬에서 실행됩니다.

시작과 선택 확정 기록으로 첫 도구 선택 전 리롤을 구분합니다. 리롤 후 재실행해도 시작 아이템을 보유 수술 도구로 오인하지 않으며, 불완전하게 읽은 화면이 확정된 도구 이력을 덮어쓰지 않습니다. 로그 근거가 없는 중간 진입에서는 도구를 임의로 없다고 가정하지 않습니다.

1.0.6은 게임 폰트의 0~9 공통 기준으로 라운드 숫자를 읽습니다. 카드 색과 밝기 경계를 함께 비교하여 아래 버튼을 테두리로 잡는 문제를 수정하고, 한글 제목은 배경색과 국소 대비를 분리해 읽습니다. 실제 경계를 제목 인식과 테두리 표시에 함께 사용합니다. 경계를 확정하지 못하면 카드 네모를 생략하고, 인식이 확실한 카드 번호와 대상 탱크 추천을 유지합니다. 진행 중 재실행해도 확실히 읽힌 도구는 복원합니다.

- 타르타로스: 초록색 굵은 테두리가 추천 선택지입니다. 상자 아이콘 옆 숫자는 예상 완주 보상입니다.
- 블러드 러스트: 카드 번호와 대상 탱크 번호, 밝은 테두리를 확인합니다. 선택과 확인은 직접 진행합니다. 호버나 선택으로 카드 위치가 바뀌면 테두리만 다시 맞추며 OCR과 추천 계산을 반복하지 않습니다.
- 1.0.9는 84만까지 부족한 점수의 평균을 줄이도록 카드와 리롤을 비교합니다. 초과 점수를 더 높은 가치로 계산하지 않습니다. 표시되는 84만 달성률은 시뮬레이션 추정입니다. 84만은 후반 수술 플랜의 추가 활성을 전제로 한 준비 목표이며, 무지개 보상 확정 수치가 아닙니다. 낮은 점수나 사망 가능성이 없어지는 것은 아닙니다.
- 목표 점수의 기대값과 달성률이 모두 같으면 최종 몬스터 총수, 남은 탱크 수가 적은 선택을 차례로 우선합니다. 점수를 희생하면서 융합/제거를 강제하지 않습니다. 전투 시간 자체를 측정하거나 예측하는 기능은 아닙니다.
- 펫 단계는 화면에 보이지 않는 도구 새로고침 횟수의 초기값입니다. 화면에서 확실히 읽은 실제 남은 횟수가 우선합니다.
- 수술 플랜(11~13라운드)은 캐릭터의 생존력과 전투 조건에 따라 선택해야 하므로 자동으로 특정 카드를 최선이라고 표시하지 않습니다.
- 읽지 못한 항목은 주황색 `인식 확인 필요` 안내로 표시합니다. 도구는 표시한 아이콘을 클릭해 설명을 열고, 카드는 클릭해 펼치세요. 카드의 `확인` 버튼은 누르지 않습니다. 수치를 가린 설명창은 안내에 따라 닫아 주세요. 확인되면 자동으로 추천을 재개합니다. 빠른 재시도 후에는 3초 간격으로 확인합니다.
- 첫 선택 전 로그나 펼친 설명으로 확인한 시작 아이템은 이 PC에 저장해 재실행 후에도 구별합니다. 설명과 아이콘의 대응이 불분명하거나 지원하지 않는 효과는 임의로 무시하지 않습니다. 미확인 도구가 여러 개면 자동 복구하지 못할 수 있습니다.

## 성능과 데이터

블러드 러스트는 선택지당 256/512/1,024회 탐색을 지원합니다. 기본은 정밀 1,024회이며 계산 스레드는 CPU 논리 코어의 절반, 최대 8개입니다. CPU 사용 설정에서 게임 우선(최대 4개), 균형(최대 8개), 추천 속도 우선(최대 12개)을 선택할 수 있습니다. 게임 프레임이 떨어지면 균형이나 빠르게를 선택하세요. 타르타로스의 인식 간격과 탐색 품질은 별도로 조절합니다.

게임 메모리를 읽거나 바꾸지 않으며, 게임에 클릭이나 키 입력을 보내지 않습니다. 캡처와 로그를 로컬에서 처리합니다. 통계와 오류를 자동 전송하지 않습니다. 설정과 로컬 기록은 실행 파일 옆 `user-data`에 저장합니다.

## 업데이트

창 하단의 `업데이트 확인`을 누르세요. 새 버전이 있으면 `변경 내용`을 읽고 `다운로드 및 업데이트`로 설치할 수 있습니다. 확인 대화상자를 거쳐 다운로드하며 취소할 수 있습니다. 파일 검증 후 오버레이가 다시 시작되고 펫 단계, 설정과 로그는 유지됩니다. 설치 실패 시 교체한 파일을 복구합니다.

`시작할 때 확인`은 실행 시 새 버전 유무만 확인하는 선택 사항입니다. GitHub 로그인 없이 공개 릴리스를 조회하며 게임 화면이나 로그는 전송하지 않습니다. 검증 정보가 없는 릴리스는 수동 다운로드 페이지로 안내합니다. 1.0.2 이하는 최신 ZIP을 한 번 수동 설치한 뒤 이 기능을 사용할 수 있습니다.

타르타로스와 블러드 러스트는 포함된 한국어 PP-OCR 모델을 사용합니다. Windows OCR과 카드 그림 비교는 보조 인식입니다. 지원 식별자 85개에 한국어 명칭을 연결했고 누락 여부를 검사합니다. 일부 제목만 읽혀 변종을 구분하지 못하면 확정하지 않습니다. 일부 특수 포션 연속 효과는 지원 범위가 제한됩니다. 모든 패치, 해상도, UI 배율에서 인식을 보장하지 않습니다. Vorax 확률표 기준일은 2026-10-22이며, 타르타로스는 v0.7.20에 포함된 모델을 사용합니다.

## 배포

다른 사람에게는 제공된 ZIP을 공유하세요. 사용 중인 폴더를 다시 압축할 때는 `user-data`, 로그, 진단 이미지와 개인 설정을 제외해야 합니다. `licenses`와 `THIRD_PARTY_NOTICES.md`를 함께 유지하세요. 게임명과 게임 자산은 권리자에게 귀속되며, 게임 제작사의 공식 도구가 아닙니다.

## 소스 빌드

`tartarus/`는 glcoder/TartarusSolver v0.7.20의 MIT 소스, `vorax/`는 DinoRaos/vorax-solver-rs 9aabc20의 MIT 소스를 기반으로 합니다. 두 저작권 고지를 보존합니다. 제한적 라이선스로 변경된 다른 솔버의 최신 코드는 포함하지 않습니다.

`build.ps1`은 .NET SDK와 로컬 Rust GNU 툴체인으로 독립 실행형 배포 폴더를 만듭니다. `package.py`는 허용된 파일만 ZIP에 담고 SHA-256과 포함 목록을 생성합니다. 공개 업로드는 별도입니다.
